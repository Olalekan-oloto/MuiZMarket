MuiZMarket authentication setup
================================

Files
-----
- auth.js: account registration, sign-in, password reset, email verification and sign-out logic.

Important
---------
auth.js alone cannot create accounts until the website's HTML and Firebase project are configured.
Do not put Firebase Admin/service-account credentials or private keys in browser code.

1. In Firebase Console, create/select your project.
2. In Authentication > Sign-in method, enable Email/Password.
3. In Authentication > Settings / Authorized domains, add the domain where the website is hosted.
4. Register a Web app in Project settings and copy its Firebase web config.
5. Before loading auth.js, define window.MUIZMARKET_FIREBASE_CONFIG with that web config.
6. Load the Firebase v8-compatible app, auth and firestore SDK scripts before auth.js. This file uses the
   namespaced SDK API: firebase.initializeApp(), firebase.auth() and firebase.firestore().
7. Ensure the HTML has these IDs:
   registerForm, loginForm, resetForm, formTitle, formSubtitle, accountMessage,
   setupNotice, forgotLink, backToLogin, accountStatus, signOutButton.
   The forms must have the field names used by FormData:
   register: fullName, username, email, password, country, phone, dob
   login: email, password
   reset: email
   Add view-switch controls with data-view="register", "login", and "reset".
8. Create and carefully test Firestore security rules for the usernames and users collections.
   The code expects usernames/{lowercaseUsername} and users/{uid}. Do not deploy permissive rules
   such as allow read, write: if true. The client-side transaction is not a substitute for secure rules.
9. Host the website over HTTPS and test registration, verification email, sign-in, password reset,
   and sign-out.

Phone numbers must include a country code, and passwords must be at least 12 characters.
The script intentionally blocks account actions if the Firebase configuration is missing.
